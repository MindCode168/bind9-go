# 2026-09-13 DNS 性能测量

打开 `report.html` 阅读报告，数据和 SVG 图表已内嵌，支持离线查看。

本次仅实际测试 ISC BIND 9.20.27。Go 版本没有可运行的 DNS 服务端，性能指标均为不可测，不能给出版本性能比较结论。

36 次正式测量覆盖 12 个条件，每组 3 次。发送 9,555,805 次、完成 9,555,392 次、未完成 413 次；不能把混合不同负载的总计当作单一场景吞吐量。

## 校验结果

- 36 轮原始日志的计数、QPS、平均/最小/最大/标准差延迟、未完成比例、响应码全部与 JSON 一致。
- RSS 峰值和资源采样数量与每轮样本一致。
- 12 组 × 3 次唯一测量完整；所有配置和查询集哈希一致。
- HTML 的全部 72 项指标汇总均按实测的中位数与范围核算；内嵌 JSON 与源文件一致。
- HTML 包含 4 张内嵌 SVG，无外部加载资源；JavaScript 语法、筛选逻辑检查通过。
- 浏览器 URL 策略阻止本地 HTML 视觉检查，未完成浏览器视觉或真实交互验收。
- CPU 公式及中间采样一致；精确起止 tick 未单独保存，无法仅由中间样本完全重建该区间 CPU 值。

正式数据见 `benchmark.json`，日志见 `logs/`。Go 包清单、宿主机环境、BIND 编译版本、查询数据、配置、实际执行脚本均在同目录保存。CPU 窗口说明和区域总 RR 数已在最终 JSON 修正，原始测量数值未改。复现方法见项目 `benchmarks/README.md`。
